# Разрешения на источники данных FinServ

Новый источник подключается только после записи здесь (кто разрешил, когда, в какой форме, что входит,
требования к ссылке). Сами письма и договоры владельцы проекта хранят у себя.

| Источник | Что берём | Основание | Требования |
|---|---|---|---|
| ISS Московской биржи | цены, свечи, индексы, облигации, купоны, КБД; сборщик коммитит в `public/data/` дневной снимок облигаций для скринера (`screener_bonds.json`: цена, НКД, доходность, оборот) и расчётные показатели (без рядов котировок) | открытый API ISS; для коммерческого сайта — договор с Мосбиржей (**проверить до публичного запуска**) | ссылка «Данные: Московская биржа» |
| Банк России | ключевая ставка, RUONIA, учётная цена золота, курсы | открытые сервисы ЦБ (XML/SOAP) | ссылка на источник |
| T-Invest API (Т-Банк) | дивиденды, мультипликаторы, сектора, комиссии фондов, **логотипы и цвета брендов** акций (эмитент), облигаций (`Bonds`, файл `tinvest_bonds.json`) и фондов (бренд ETF — управляющая компания) | разрешение Т-Банка на использование в студенческом проекте (см. CLAUDE.md); токен `TINVEST_TOKEN` в GitHub Secrets, только чтение | ссылка «Данные: T-Invest API» |
| RusETFs | комиссии, УК, СЧА фондов | разрешение авторов rusetfs.com, JSON-API скринера раз в сутки | ссылка на rusetfs.com обязательна |
| НПФ: составы портфелей и отчёты о структуре | данные раскрытия НПФ (п. 1.2.5 Указания Банка России № 5175-У и отчёты фондов о структуре) и Банк России; собраны владельцем проекта в приложении «Монитор портфелей НПФ» | обновляется **вручную**: владелец присылает HTML, импорт `python -m scripts.import_npf` → `public/data/npf/` (в файлах — даты `built` сборки и `monitorUpdated` обновления структуры; сейчас 15.11.2026 и 12.11.2026) | ссылка на источник: раскрытие НПФ и Банк России; исходный HTML в репозиторий не кладётся |

## Индексы (`public/data/indices.json`)

* Раздел «Индексы» строится сборщиком из рядов ISS Мосбиржи и Банка России (ряды индексов полной доходности и ценовых, золото ЦБ, RUONIA). В файл попадают **производные показатели** (доходность за периоды, среднегодовая, максимальная просадка, волатильность) и **нормированный к 100 месячный ряд** за последние до 10 лет (для мини-графика) — не исходные котировки.
* **Открытый вопрос:** подтвердить у Московской биржи, что публикация нормированных месячных рядов индексов на сайте входит в условия использования данных ISS (см. строку про ISS в таблице: для публичного коммерческого запуска нужен договор).
* Стартовый файл создан из эталонных месячных рядов репозитория (`tests/fixtures/`) и подписан «эталонные месячные ряды (демо)»; первый успешный ночной сбор заменяет его свежими данными.

## Логотипы компаний (T-Invest)

* Сборщик берёт из ответов T-Invest API `Shares`/`Etfs` поля бренда (`logoName`, `logoBaseColor`) и пишет их в
  `public/data/tinvest_shares.json` / `tinvest_etfs.json`.
* Картинки сайт загружает с CDN Т-Банка `https://invest-brands.cdn-tinkoff.ru/<logo>x160.png` — это часть той же
  экосистемы T-Invest, на которую получено разрешение. **Открытый вопрос:** подтвердить у Т-Банка, что показ
  логотипов с их CDN входит в разрешение. Если нет — сайт уже умеет показывать вместо логотипа кружок с буквами
  тикера в фирменном цвете (`web/js/logo.js`). Чтобы отключить картинки, в `web/js/logo.js` убрать формирование URL CDN — останутся кружки.
* Логотипы — товарные знаки их владельцев, используются только для узнавания бумаги рядом с её тикером.
