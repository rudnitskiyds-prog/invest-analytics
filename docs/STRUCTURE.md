# Структура сайта ИнвестАналитики

Ориентир — информационная архитектура PortfoliosLab (portfolioslab.com): набор разделов, типы страниц
и инструменты. Повторяем **структуру и функции**, а не дизайн, тексты, названия и бренд — их делаем
свои. **Все данные — только российские:** ISS Мосбиржи и Банк России. Расчёты в основном в рублях; у валютных облигаций — в валюте режима
(TQOY — CNY, TQOD — USD), суммы пересчитываются в рубли по курсу ЦБ.

Статусы: ✅ есть в веб-версии · 🟡 есть в Python (`core/`), нужно перенести в `web/lib` · ⬜ нет ·
🔒 нужен бэкенд с аккаунтами.

## 1. Карта сайта

```
/                              главная: поиск по тикерам, популярные бумаги, входы в разделы
/symbol/{TICKER}               страница бумаги: акция, БПИФ/ПИФ, облигация, индекс, металл
/compare?s=A,B,…               сравнение 2–10 бумаг
/portfolios/lazy               «ленивые» портфели (российские аналоги)
/portfolios/strategies         стратегии
/portfolio/{slug}              страница портфеля
/portfolios/community   🔒     портфели пользователей
/tools                         каталог инструментов
/tools/{tool}                  страница инструмента (см. п. 3)
/screener/stocks               скринер акций
/screener/funds                скринер фондов (БПИФ/ОПИФ/ЗПИФ)
/screener/bonds                скринер облигаций (ОФЗ, корпоративные) — нашего отличия нет у PortfoliosLab
/docs                          методика: формулы, допущения, источники
/blog                          статьи
/account                🔒     мои портфели, списки наблюдения, сохранённые фильтры
```

## 3. Инструменты `/tools/{tool}`

**Анализ эффективности:** анализ портфеля (полный отчёт: структура, рейтинг, коэффициенты по позициям,
просадки, корреляции с бенчмарком 1/3/5/10 лет) 🟡 · динамика портфеля (бэктест с пополнениями) ✅ ·
отдельные страницы коэффициентов: Шарп ✅, Мартин ✅ (стр. бумаги), Трейнор ✅, Сортино ✅, Омега ✅, Кальмар ✅,
Саммерс (Омега относительно рынка) ⬜, альфа ✅.

**Риски:** просадки ✅, CVaR ✅, индекс язвы ✅, VaR ✅, волатильность close-to-close ✅, Паркинсон ✅,
Гарман–Класс ✅, Роджерс–Сатчелл ✅, Янг–Чжан ✅, бета ✅.

**Оптимизация:** среднее–дисперсия (граница, макс. Шарп, мин. дисперсия) ✅ · защита от обвалов
(мин. CVaR) ⬜ · сбалансированный рост ⬜ · максимизация роста (макс. геометрическая доходность) ⬜ ·
паритет риска ⬜ · HRP ⬜ · HERC ⬜ · максимальная диверсификация ⬜ · бэктест с переоптимизацией по
скользящему окну (walk-forward) ⬜.

**Диверсификация и сравнение:** анализ диверсификации (кластеры, низкокоррелированные замены) ⬜ ·
корреляции активов (матрица) 🟡 · сравнение бумаг ⬜ · сравнение 2–10 портфелей ✅ (через бэктест).

Ввод портфеля во всех инструментах — единый компонент: тикеры, доли, импорт CSV, загрузка сохранённого
портфеля 🔒; параметры — ребалансировка, бенчмарк (любой тикер), период (безрисковая ставка — автоматически, по датам периода).

## 4. Портфели

Раздел «Портфели и стратегии» по образцу portfolioslab.com/ru/strategies (`core/analytics/portfolios.py`,
`public/data/portfolios.json`, сборщик — шаг «Портфели»). История — по индексам полной доходности, блок
«Как повторить» — БПИФ и их комиссии (RusETFs). Streamlit 🟡 (`pages/8_Портфели.py`), веб-версия ⬜.

* **Ленивые** (этап 1, постоянные доли) 🟡: Лежебока плюс, 60/40, Постоянный портфель Брауна (он же «вечный»,
  готовый фонд TRUR), Всепогодный Далио (электроэнергетика — MEEUTR, история с 2014 г.), 40/40/20,
  Баффетт 90/10, Три фонда 50/30/20 (акции / ОФЗ / золото), Только ОФЗ (бенчмарк RGBITR), Индекс + денежный
  рынок 70/30, Дивидендный (IRDIVTR, с 2021 г.). Не сделано: ОФЗ-лесенка, «голубые фишки» ⬜.
* **Тематические** 🟡: отраслевые индексы полной доходности Мосбиржи — нефтегаз, финансы, металлы и добыча,
  потребительский, электроэнергетика, химия, транспорт (с 2014 г.), IT (с 2021 г.). Телеком — индекс не
  рассчитывается с 03.2026; индекса экспортёров нет.
* **Динамические стратегии** (этап 2) ⬜: ротация секторов по моментуму, двойной моментум, тренд по MCFTR,
  минимальная волатильность — нужно расширение движка бэктеста.
* **Страница портфеля** 🟡: описание и правила, состав (целевые и текущие доли), рост 100 000 ₽ против
  бенчмарка, доходность по периодам и месяцам, коэффициенты за 1/5/10 лет/всё время, просадки, журнал
  ребалансировок, «Как повторить», «Открыть в бэктесте».
* **Листинг** 🟡: 1Д, YTD, 10 лет CAGR, рейтинг (за 5 лет), макс. и текущая просадка, комиссия фондов,
  Шарп, Сортино, Омега, Мартин, Кальмар, индекс язвы (за 1 год); сортировка, выбор колонок, Excel,
  диаграмма «риск — доходность». Дивидендной доходности в листинге нет (портфели на индексах полной
  доходности) ⬜.

## 5. Скринеры

Одна таблица с фильтрами, выбором колонок, сортировкой, пагинацией и экспортом.
* **Акции** (TQBR, SECTYPE 1/2/D): сектор, отрасль, доходности, див. доходность, мультипликаторы,
  рейтинг, просадки, коэффициенты. Сектор — по вхождению в секторные индексы Мосбиржи (ISS analytics
  индексов MOEXOG, MOEXFN, MOEXMM, …) ⬜. Мультипликаторы и сектор — T-Invest API.
* **Фонды** (TQBR SECTYPE J/9/A/B): тип, УК, СЧА, класс активов, комиссия (RusETFs), доходности, коэффициенты 🟡.
* **Облигации** (TQOB, TQCB): доходность, дюрация, купон, погашение, оферта, листинг, оборот 🟡.

Метрики для скринеров и рейтингов считаются **заранее, раз в сутки**, сборщиком (GitHub Actions →
`public/data/screener_*.json`), а не в браузере у каждого пользователя.

## 6. Аккаунты 🔒

Мои портфели, списки наблюдения (до 10), сохранённые фильтры скринера, публикация портфелей в
«Портфели пользователей», обсуждения. Требует бэкенда: Yandex Cloud Functions + Managed PostgreSQL,
вход по почте/Яндекс ID; данные пользователей хранятся в РФ (152-ФЗ).

## 8. Этапы

1. ✅ **Каркас и страница бумаги** (ветка `feature/phase1-symbol`). Многостраничная навигация `web/` (маршруты из п. 1), поиск по
   тикерам, `/symbol/{TICKER}` со всеми блоками без пробелов в данных, ночной сборщик метрик по
   всем бумагам (рейтинги, моментум), недостающие метрики (Мартин, индекс язвы, R², capture,
   OHLC-волатильности).
2. **Инструменты.** Единый ввод портфеля, отчёт «анализ портфеля», сравнение бумаг, корреляции,
   диверсификация, оптимизация (паритет риска, HRP, HERC, макс. диверсификация, мин. CVaR, макс.
   рост), walk-forward.
3. **Портфели и скринеры.** Ленивые портфели и стратегии с листингом, скринеры акций, фондов и облигаций.
4. **Пробелы данных.** Дивиденды, TER, мультипликаторы, курсы валют.
5. **Аккаунты** 🔒 и портфели пользователей.
6. **Контент.** `/docs`, `/blog`.
