# Данные для статического сайта

Файлы обновляет `scripts/collect_data.py` по расписанию (`.github/workflows/collect-data.yml`).
Не редактируйте их вручную — изменения перезапишутся при следующем сборе.

| Файл | Что внутри |
|---|---|
| `cbr_gold.json` | Учётная цена золота Банка России, руб./г, с 2008 г. |
| `ruonia_rate.json` | Ставка RUONIA, % годовых |
| `ruonia_index.json` | Накопленный индекс денежного рынка по RUONIA (база 100) |
| `key_rate.json` | Ключевая ставка, доля годовых, с 13.09.2013 |
| `status.json` | Результат последнего сбора по каждому источнику |

Котировки Мосбиржи сюда не попадают: браузер получает их напрямую из ISS.
